# goit-algo2-hw-02

# Домашнє завдання GoIT: Алгоритми 2

Цей репозиторій містить рішення для двох завдань домашньої роботи:

1. **Завдання 1:** Пошук мінімального та максимального елементів у масиві за методом "розділяй і володарюй" (Divide & Conquer).
2. **Завдання 2:** Оптимізація черги завдань 3D-принтера з урахуванням пріоритетів та обмежень принтера (жадібний алгоритм).

---

## 🟢 Завдання 1: Пошук мінімуму та максимуму

### Використання

1. Відкрийте термінал у директорії з файлом `task1.py`.
2. Запустіть команду:

```bash
python3 task1.py

```

## 🟢 Завдання 2: Оптимізація черги 3D-принтера

## Використання

1. Відкрийте термінал у директорії з файлом task2.py.

2. Запустіть команду:

```bash
python3 task2.py
```

## Особливості реалізації:

- Використовується dataclass для завдань (PrintJob).

- Завдання сортуються за пріоритетом (1 → найвищий).

- Групування моделей для друку з урахуванням:

- max_volume — максимальний об'єм друку

- max_items — максимальна кількість моделей у групі

- Час друку групи = максимальний час серед моделей у групі.

- Використовується жадібний алгоритм
